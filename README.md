# COMP 2510 Midterm Review

## How to use

In midterm/ and final/ there will be some modules focused on different concepts. Read through the module files i.e. `basics/basics.c` these files will have code with questions to answer. Try to use google and stack overflow to try and answer questions, maybe ask your friends, if you're really stuck try asking AI but I'd avoid this where possible.

To compile and run the different modules in midterm/ and final/ run the command:
```sh
make run-<module-name>
```

i.e. to run pointers module:
```sh
make run-pointers
```

There may be some warnings because some of the code is designed to show you what not to do.

## Test Material

Each module will have some question where you are provided a function declaration and asked to implement the logic yourself. If you're stuck or just want to see how I did it each module with have a `<function_name>_answer.c` for you to check. Try it yourself first.

Both midterm/ and final/ have a markdown file with multiple choice questions titled `quiz.md`. Answers are provided with full explanations in `quiz_answers.md`.

Both midterm/ and final/ also have `practice_test.md` these will be questions asking whether or not something is a runtime error, compile error, or no error with maybe some other questions thrown in. Answers will be provided in `practice_test_answers.md`. Do note, the in depth answers for this were largely made with AI, I made a lot of questions and writing out each answer myself would have taken hours. I did go through and fact check them to the best of my ability. If you notice any errors please let me know.
